## Project state

ShadowMap is a single-module Android app that started from the default Android Studio "Empty Activity" (Jetpack Compose) template and now renders a full-screen Mapbox map from `MainActivity`. There is no other custom architecture, networking, persistence, or navigation yet. When adding features, you are establishing the initial structure rather than following an existing convention.

- Package / namespace / applicationId: `com.example.shadowmap`
- Language: Kotlin, UI toolkit: Jetpack Compose (Material 3)
- Min SDK 24, target/compile SDK 37
- Single Gradle module: `:app`
- Map: Mapbox Maps SDK for Android v11 (`com.mapbox.maps:android`) + its Compose extension (`com.mapbox.extension:maps-compose`), version pinned in `gradle/libs.versions.toml` as `mapboxMaps`

### Mapbox token setup

Two separate Mapbox tokens are involved, and neither should ever be committed:

- **Secret downloads token** (scope `DOWNLOADS:READ`) — authenticates Gradle against Mapbox's private Maven repo. Configured in `settings.gradle.kts` via `providers.gradleProperty("MAPBOX_DOWNLOADS_TOKEN")`. Set it in the user-level `~/.gradle/gradle.properties` (never the project's own `gradle.properties`, which is version-controlled). In practice the public release artifacts have resolved fine without it, but set it if a private/restricted Mapbox package is ever needed.
- **Public access token** (`pk.*`) — used by the app at runtime to fetch map tiles. Lives in `app/src/main/res/values/mapbox_access_token.xml` as the `mapbox_access_token` string resource, which the SDK reads automatically. That file is listed in `.gitignore` so the real token never gets committed — only a placeholder value ships in source control.

## Commands

Use the Gradle wrapper (`./gradlew`) from the repo root for all build/test/lint operations.

```bash
# Build debug APK
./gradlew assembleDebug

# Run unit tests (app/src/test)
./gradlew test

# Run a single unit test class or method
./gradlew test --tests "com.example.shadowmap.ExampleUnitTest"
./gradlew test --tests "com.example.shadowmap.ExampleUnitTest.methodName"

# Run instrumented tests (app/src/androidTest) - requires a connected device/emulator
./gradlew connectedAndroidTest

# Install debug build to a connected device/emulator
./gradlew installDebug

# Clean build outputs
./gradlew clean
```

There is no linter (ktlint/detekt) configured — the only style setting is `kotlin.code.style=official` in `gradle.properties`.

## Structure

- `app/src/main/java/com/example/shadowmap/MainActivity.kt` — app entry point, hosts Compose content in a single `Activity`
- `app/src/main/java/com/example/shadowmap/ui/theme/` — Compose theme (`Color.kt`, `Theme.kt`, `Type.kt`), generated by the template
- `app/src/test/` — local JVM unit tests (JUnit 4)
- `app/src/androidTest/` — instrumented tests (AndroidX Test + Espresso, Compose UI test)
- Dependency versions are centralized in `gradle/libs.versions.toml` (version catalog) — add new dependencies there rather than hardcoding versions in `app/build.gradle.kts`
